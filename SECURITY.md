# Security policy

## Report a vulnerability

Use **Report a vulnerability** on the [GitHub Security page](https://github.com/akz142857/InputTranslator/security) when private reporting is available. Otherwise, open an issue in [GitHub Issues](https://github.com/akz142857/InputTranslator/issues) asking for a private contact and share the vulnerability details after the maintainer replies.

In your private report, include the InputTranslator version, macOS version, affected feature, observed impact, and a minimal example. If relevant, specify the terminal and assistant in use. Use examples with synthetic text and remove credentials, personal data, and private conversation content from attachments.
